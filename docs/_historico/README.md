# Historico documental

Esta carpeta conserva documentos que fueron utiles durante diseno, migracion,
validacion o investigacion, pero que ya no deben leerse como reglas operativas
vigentes.

Regla:

- Si un documento de esta carpeta contradice un documento rector en `docs`, manda
  el documento rector vigente.
- No borrar estos archivos sin una revision explicita: contienen contexto de
  negocio y casos testigo.
- No implementar funcionalidad nueva tomando esta carpeta como fuente unica.
